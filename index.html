Set up MIS

Mistake Intelligence System — study the way you solve

  1. Keep this file somewhere permanent — Documents is a good spot. The whole app lives inside this one file.
  2. In your browser menu (⋮ top-right), choose Cast, save and share → Install page as app in Chrome, or Apps → Install this site as an app in Edge.
  3. Tick Create Desktop shortcut. You get a desktop icon that opens MIS in its own window, like a normal app.

Your data is saved privately in this browser on this computer — nothing is uploaded anywhere. If you move the file after installing, redo step 2 so the shortcut points at the new location.
