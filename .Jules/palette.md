## 2025-09-11 - Search Input Clear Button and ARIA Label Pattern
**Learning:** Text search inputs across table views and filter bars benefit from both an explicit `aria-label` describing the search target fields and an inline clear button with `aria-label="Clear search"` that appears when query text is non-empty.
**Action:** Always add `aria-label` to filter search inputs and ensure search inputs with query text feature a single-click inline clear button with proper keyboard focus ring and accessible label.
